libqr examples

No build step — these pages import ../src/index.js directly.

Serve the repository root, not this directory. These pages reach up into src/, so a server rooted at examples/ cannot see it. From the repository root:

npm run serve        # then http://localhost:8974/examples/

npx http-server .    # then http://localhost:8080/examples/

Get it wrong and each page says so, with the commands — rather than leaving a bare 404 in the console.

  • basic — SVG output, live options
  • canvas — drawing into a canvas you own, and PNG download
  • custom element — <qr-code> driven by attributes
  • centre logo — the two size limits, and what happens past them
